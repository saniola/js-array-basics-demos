# JS Array Basics Demos

Small vanilla JavaScript exercises covering basic array and string operations.

## Features

- **Task 1** — `slugify` converts a title string into a lowercase, hyphen-joined slug
- **Task 2** — `makeArray` concatenates two arrays and truncates the result to a maximum length
- **Task 3** — `filterArray` returns the numbers from an array that are greater than a given value

## Technology

- Vanilla JavaScript

## Running

Open `index.html` in a browser with the developer console open, or run each task script directly with Node:

```
node js/task-01.js
node js/task-02.js
node js/task-03.js
```
